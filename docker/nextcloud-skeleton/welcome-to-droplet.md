# Welcome to Droplet

Your personal cloud is ready. This guide will help you upload files and sync your devices so everything stays in one place — privately, on your own hardware.

---

## How It Works

```
 +------------+       +------------------+       +------------+
 |   Phone    | <---> |                  | <---> |   Laptop   |
 +------------+       |     Droplet      |       +------------+
                      |   (your device)  |
 +------------+       |                  |       +------------+
 |   Tablet   | <---> |   All your files | <---> |  Desktop   |
 +------------+       |   stored locally |       +------------+
                      +------------------+
```

Droplet keeps your files on hardware you own. Sync across all your devices over your local network — no third-party cloud required.

---

## 1. Upload Files via the Web Dashboard

Open your browser and navigate to your Droplet dashboard.

```
 +--------------------------------------------------+
 |  Droplet                              [+ Upload]  |
 |--------------------------------------------------|
 |                                                    |
 |   Drag files here or click [+ Upload]              |
 |                                                    |
 |   +----------+  +----------+  +----------+        |
 |   | vacation |  |  work    |  |  music   |        |
 |   | photos/  |  |  docs/   |  |          |        |
 |   +----------+  +----------+  +----------+        |
 +--------------------------------------------------+
```

**Steps:**

1. Open your browser and go to your Droplet address
2. Log in with your account
3. Click **+ Upload** in the top-right corner, or drag files directly into the window
4. To create folders, click **New Folder** and give it a name
5. Files are available immediately from any synced device

**Tip:** Organize files into folders (Photos, Documents, Music, etc.) to keep things tidy across all your devices.

## 2. Sync Your Desktop (macOS, Windows, Linux)

Install the Droplet sync client to keep folders on your computer automatically in sync with your Droplet device.

```
  Your Computer                    Droplet Device
 +------------------+            +------------------+
 |  ~/Droplet/      |    sync    |  Your Files      |
 |   Photos/    -------->  <--------   Photos/      |
 |   Documents/ -------->  <--------   Documents/   |
 |   Projects/  -------->  <--------   Projects/    |
 +------------------+            +------------------+
        Changes sync automatically in both directions
```

**Steps:**

1. Download the sync client for your platform:
   - **macOS:** Download from the App Store or the desktop client website
   - **Windows:** Download the installer from the desktop client website
   - **Linux:** Install via your package manager (`apt`, `dnf`, etc.)

2. Open the app and enter your Droplet server address when prompted

3. Log in with your Droplet account credentials

4. Choose which folders to sync:
   - **Sync everything** — mirrors your full Droplet storage
   - **Select folders** — pick specific folders to keep on this computer

5. Choose a local folder (default: `~/Droplet`)

6. Click **Connect** — your files will begin syncing

**What happens next:**
- Any file you add to the local folder appears on Droplet (and all other synced devices)
- Any file you upload via the web dashboard appears in your local folder
- Edits sync automatically in both directions

## 3. Sync Your Phone or Tablet (iOS, Android)

Keep your mobile photos, videos, and documents backed up to Droplet automatically.

```
  +----------------+                  +------------------+
  |  Your Phone    |     auto-sync    |  Droplet Device  |
  |                |                  |                  |
  |  Camera Roll  -|---------------->|  Photos/         |
  |  Downloads    -|---------------->|  Mobile/         |
  |                |                  |                  |
  |  Browse & view |<----------------|  All your files  |
  +----------------+                  +------------------+
```

**Steps:**

1. Install the mobile sync app:
   - **iOS:** Download from the App Store
   - **Android:** Download from Google Play or F-Droid

2. Open the app and tap **Log in**

3. Enter your Droplet server address and credentials

4. Enable **Auto Upload** for photos and videos:
   - Go to **Settings > Auto Upload**
   - Choose the destination folder on Droplet (e.g., `Photos/Mobile`)
   - Select whether to upload on Wi-Fi only or also on cellular

5. Browse all your Droplet files from the app — open, share, or download anything on the go

---

## 4. Tips for Getting Started

- **Start with photos** — enable auto-upload on your phone so every picture is safely stored on Droplet
- **Create a shared folder** — share a folder with family members so everyone can access shared documents and photos
- **Use selective sync** — on laptops with limited storage, only sync the folders you need day-to-day
- **Access anywhere on your network** — all your devices on the same network can reach Droplet instantly
