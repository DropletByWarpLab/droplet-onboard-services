Connect securely to your Droplet

The dashboard uses HTTPS over your office network or WireGuard connection.

Trust the Droplet certificate on this device using ./scripts/trust-droplet-cert.sh (Windows: trust-droplet-cert.ps1). For a custom internal DNS name, pass that hostname to the shell script or use -HostName on Windows.

The certificate must cover the internal DNS name you use. If this Droplet still has an old public certificate, its administrator needs to install a local certificate for the internal name.
