# Design-token ratchet — grandfathered debt.
#
# Enforced by `scripts/check-dashboard-classes.sh` (guards 3–5), run by
# `npm run lint:dashboard-classes` from apps/web-dashboard.
#
# Format: `<rule> <path>`, path relative to apps/web-dashboard/src.
# A hit in a listed file passes; a hit anywhere else fails the build.
#
# Seeded from origin/main @ 149500ba (2026-08-04): 94 legacy-token files
# (855 hits), 22 accent-alpha files (44 hits), 14 white-on-accent files
# (15 hits). Those numbers only go down.
#
# THIS FILE MAY ONLY SHRINK. Never add a line to make CI green — fix the
# code instead. When you clean a file, delete its line here in the same
# PR; the guard hard-fails on an entry that no longer matches, because a
# stale entry is how a ratchet quietly stops ratcheting.
#
# Rules:
#   legacy-token     pre-DESIGN.md tokens (dp-card, dp-btn*, dp-input,
#                    bg-surface-*, text-label-*, text-accent, bg-accent,
#                    border-separator, bg-separator, bg-label-*,
#                    ring-accent, --color-accent*). Valid CSS, but not
#                    the ratified system. See DESIGN.md.
#   accent-alpha     `-accent/NN`. Silently dropped by Tailwind: the
#                    `accent` color is `var(--color-accent)` with no
#                    <alpha-value> placeholder and the variable is a hex.
#                    Every entry below is a live bug — mostly focus rings
#                    that render no ring at all. Paying this down is its
#                    own PR (a visual change), not a lint change.
#   white-on-accent  `text-white`/`bg-white`/`#fff` on an accent fill.
#                    On-Accent flips to #1d1d1f in dark mode, so these
#                    are dark-mode contrast failures. Also its own PR.
#
# Out of scope entirely (never listed here, never scanned): the setup
# wizard + auth routes and the components they solely own (WARP-1078),
# and `__tests__/` + co-located `*.test.ts(x)`.
