# WARP-436 RAG Phase 2 — RAGAS eval harness. NOT a production dependency.
#
# This file lives only in tests/retrieval-eval/ragas/. Production code
# (services/file-indexer, apps/orchestrator, services/ai-gateway) must
# never import from this directory. The harness is offline-only and runs
# under scripts/test-rag.sh --with-ragas (added in batch C, step 2.5).
#
# Pinning rationale (WARP-1406 — keep in LOCKSTEP with
# services/rag-eval/requirements.txt; there is no CI diff-guard, so the
# lockstep is manual and deliberate):
#   - ragas: 0.2.13 — the version whose metrics API ragas_runner.py is
#     written against (LangchainLLMWrapper + LLMContextPrecisionWithReference
#     et al.). The previous 0.4.3 pin here could never run this runner
#     (0.4 does not export the metric names/wrapper path the runner uses)
#     and had silently drifted from the service file. Bump both files
#     together, deliberately, with a re-baseline run.
#   - langchain*: capped to the 0.3 line. ragas 0.2.x (and 0.4.x) imports
#     langchain_community.chat_models.vertexai unconditionally, which
#     langchain-community 1.x (2026) removed — unpinned, a fresh install
#     crashes at `from ragas import evaluate`.
#   - langchain-openai: the runner's judge path (make_chat_llm) uses
#     langchain_openai.ChatOpenAI pointed at local Ollama's OpenAI-compat
#     endpoint by default.
#   - datasets / pandas: needed by ragas.evaluate() return shape.
#   - pyyaml: load goldens.yaml + queries.yaml.
